# Roles — qa-test

| Role         | Permissions                                                   | Current holders  |
|--------------|---------------------------------------------------------------|------------------|
| Owner        | All permissions; approves CONSTITUTION changes; manages users | Osvaldo J. Filho |
| QA Engineer  | Run tests, write module memory, create sessions, add skills   | —                |
| Observer     | Read-only access to reports and dev-docs                      | —                |

## Role Descriptions

### Owner
Full control over the project memory, harness code, and governance rules. Responsible for promoting skills from DRAFT → ACTIVE and approving decisions that affect multiple modules.

### QA Engineer
Runs QA cycles, authors session records, and documents bugs and decisions in module files. May create DRAFT skills but not promote them without Owner review.

### Observer
Can read reports, browse the dev-docs dashboard, and follow sessions but cannot write memory or run the harness on production hardware.
